Import

How the data is laid out

From the Reference Manual (pp. 152–154): dots go left to right from the top-left of the 8×8 cell. In 16 colours each dot is one hex digit, so a row is 4 bytes; in 256 colours each dot is one byte, so a row is 8 bytes. Colour 0 is always transparent. SETCHR BG,pattern,count,READ reads count patterns from DATA; it reads each DATA line to its end. On the 16-colour text screen a dot shows palette entry code×16+dot, where code is the COLOR number in PUTCHR bits 15–12. On a 256-colour screen the PUTCHR character number is pattern×2.
