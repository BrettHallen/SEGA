# Documentation for GAME BASIC

## Original Japanese manuals
Scans of the original manuals. The Reference Manual is split in two because of its size. The scans are copyrighted, so they are kept out of the public repository.
- Tutorial Manual: `GAME_BASIC_for_SEGA_SATURN_Tutorial_Manual_JP.pdf` (the page images are also in `Tutorial_Manual_JP/`)
- Reference Manual, front matter and Chapter 1 (up to p. 228): `GAME_BASIC_for_SEGA_SATURN_Reference_Manual_Part1_JP.pdf`
- Reference Manual, Chapter 2 and back matter (from p. 229): `GAME_BASIC_for_SEGA_SATURN_Reference_Manual_Part2_JP.pdf`
