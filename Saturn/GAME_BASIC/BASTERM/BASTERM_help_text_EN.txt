BASTERMについて4
  EN: About BASTERM4
BASTERMはGAME BASIC for SEGASATURNのプログラム開発を支援するWindows95対応の通信ソフトウェアです。本ソフトウェアを使用するにはWindows95マシンとGAME BASIC for SEGASATURNが正しく接続されていなければなりません。接続方法について詳しくはマニュアルをご参照ください。
  EN: BASTERM is Windows 95 communications software that supports program development for GAME BASIC for SEGASATURN. To use this software, the Windows 95 machine and GAME BASIC for SEGASATURN must be correctly connected. For details on how to connect them, please refer to the manual.
インストール
  EN: Installation
BASTERM.EXE, BASTERM.HLP, BASTERM.CNTの３つのファイルを同じフォルダにコピーしてください。通信ケーブルを接続しGAME BASIC for SEGASATURN側のボーレートを設定します（詳しくはマニュアルをご参照ください）。BASTERM.EXEのアイコンをダブルクリックして起動し、まずは
  EN: Copy the three files BASTERM.EXE, BASTERM.HLP and BASTERM.CNT into the same folder. Connect the communication cable and set the baud rate on the GAME BASIC for SEGASATURN side (see the manual for details). Double-click the BASTERM.EXE icon to start it, then first use the
[通信条件]コマンド
  EN: [Communication Settings] command
でケーブルを接続したポート番号を選択し、GAME BASIC for SEGASATURNと同じボーレートを選択します。設定がすんだらちゃんと接続できるか、
  EN: to select the port number the cable is connected to, and select the same baud rate as GAME BASIC for SEGASATURN. Once the settings are done, check that you can actually connect by running the
[接続]コマンド
  EN: [Connect] command
を実行して接続できるかを確認してください。
  EN: and confirming that a connection is made.

ファイル名
  EN: File name
元のファイル名と違う名前でファイル名を入力します。ファイル名は半角 8 文字 までで指定しけます。拡張子は自動的に「.b」が付けられます。ファイル名自体としては全角文字（漢字など）を使用したり、８文字以上のロングファイル名をつけることはできますが、その場合はBASTERMを介して送受信する方法以外ではGAME BASIC for SEGASATURN側で扱うことができなくなります。
  EN: Enter a file name different from the original one. File names can be up to 8 half-width (single-byte) characters. The ".b" extension is added automatically. You can use full-width characters (kanji etc.) in the file name itself, or give it a long file name of more than 8 characters, but in that case GAME BASIC for SEGASATURN will not be able to handle the file other than by sending/receiving it through BASTERM.
ファイルの種類
  EN: Files of type
保存したい文書のファイル形式を選択します。基本的にBASTERMがサポートしている形式は「.b」ですが、例えば別のアプリケーションで取り込むために「.txt」ファイルにセーブしたいような場合には「*.*」を選択してから、拡張子まですべて入力してください。
  EN: Select the file format of the document you want to save. The format BASTERM basically supports is ".b", but if, for example, you want to save as a ".txt" file to import into another application, select "*.*" and then type the full name including the extension.
