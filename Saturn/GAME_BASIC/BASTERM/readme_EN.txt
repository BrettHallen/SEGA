Release Notes

For instructions on using BASTERM, start BASTERM either by running
"Programs/BASTERM/BASTERM" from the Start menu or by
double-clicking the BASTERM.EXE icon, then select Help from the
Help menu and refer to the help file that is displayed.

- How to uninstall
To remove the installed application, open
[Add/Remove Programs] in the [Control Panel] and
select [BASTERM].
