BASTERMについて4
BASTERMはGAME BASIC for SEGASATURNのプログラム開発を支援するWindows95対応の通信ソフトウェアです。本ソフトウェアを使用するにはWindows95マシンとGAME BASIC for SEGASATURNが正しく接続されていなければなりません。接続方法について詳しくはマニュアルをご参照ください。
インストール
BASTERM.EXE, BASTERM.HLP, BASTERM.CNTの３つのファイルを同じフォルダにコピーしてください。通信ケーブルを接続しGAME BASIC for SEGASATURN側のボーレートを設定します（詳しくはマニュアルをご参照ください）。BASTERM.EXEのアイコンをダブルクリックして起動し、まずは
[通信条件]コマンド
でケーブルを接続したポート番号を選択し、GAME BASIC for SEGASATURNと同じボーレートを選択します。設定がすんだらちゃんと接続できるか、
[接続]コマンド
を実行して接続できるかを確認してください。
基本的な操作
BASTERMのエディタか他のテキストエディタでプログラムを作成してください。BASTERMはテキストファイルを扱います。プログラムが完成したら
[送信]コマンド
でプログラムを送信し、
[プログラム実行]コマンド
でプログラムを実行します。実行中のキー操作やGAME BASIC for SEGASATURN側でのプログラムの修正には、
[キー送信]コマンド
でキー入力をGAME BASIC for SEGASATURNに送るようにします。修正した結果は
[受信]コマンド
でBASTERMの編集画面に取り込み保存することができます。

なお、一度切断するとGAME BASIC for SEGASATURNがオープン中のファイルはWindows側で一方的にクローズされますので、再接続後にGAME BASIC for SEGASATURNからそのファイルにアクセスするとエラーになります。重要なデータをアクセス中は切断する前にGAME BASIC for SEGASATURN側でオープンしているファイルを忘れずにクローズしてください。

[キー送信] コマンド ([通信] メニュー)
キー送信コマンドのダイアログが表示されている間、BASTERMに入力されたキーをそのままGAME BASIC for SEGASATURNに送信します。通常の文字の他にカーソルキー・コントロールキー・ファンクションキーなどの送信も可能ですが、F10やCTRL+Breakなどの一部のキーは使用できません。
キー送信中には他のコマンドは使用できません。キー送信を止めるにはダイアログをクリックするか、ALT-Kをキー入力します。
【注意】
[キー送信]を開始する時に　ALT-Kのショートカットを使った場合、内部の処理の関係でタイミングによって[キー送信]ダイアログを開いてすぐ閉じてしまったり、逆になかなか開かないことがあります。このような時は　CTRL-K で[キー送信]ダイアログを開き、閉じるときに ALT-K を使用してみてください。
キー送信はGAME BASIC for SEGASATURNのポリゴン表示など重たいプロセスが走っている場合には、エラーになる（タイプした文字が出ない、意図しない文字が出る）場合があります。このような場合は F12 を押せばポリゴン表示をオフにすることができます（ただしキー操作によりポリゴン表示をオフにした場合には、その後にプログラムをContinueしたり、ダイレクトコマンドでオブジェクトを操作しても、ポリゴンは再表示されません）。
また[キー送信] はGAME BASIC for SEGASATURNに対してのみ有効です。他のキーボードを使用するソフトウェアでこの機能を使ってキーボードの代わりにすることはできません。
