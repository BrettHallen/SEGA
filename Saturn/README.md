# Sega Saturn Stuff

## [GAME BASIC](/Saturn/GAME_BASIC)
Documentation (scanned Japanese & translated English) plus modern cross-platform development tools (VS Code extension).

## [Saturn Keyboard](/Saturn/Keyboard)
A recreation of the Saturn keyboard.  Still needs some work (as of Nov 2026).

## [Saturn Region Patcher](/Saturn/Python_Region_Patcher)
A Python version of [Madrom's](https://madroms.satakore.com) Windows-only ISO region patcher.

## [Windows Communication Cable](/Saturn/Windows_Communication_Cable)
Information about the RS232-to-Saturn serial cable used with GAME BASIC.  It's essentially just an RS232-to-TTL converter, DB25 on one end and Saturn serial on other.<br>

Not really needed in 2026 ... you should be able to use a USB-to-TTL converter and then (somehow) connect to the three relevant pins on the Saturn.
